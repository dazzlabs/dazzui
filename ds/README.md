# @dazzlabs/dazzui-ds

The DazzUI design system: the design tokens every platform package is
built from, authored in [DTCG](https://tr.designtokens.org/) JSON and built
with [Terrazzo](https://terrazzo.app/).

This package holds no components, and nothing imports it at runtime. It is a
**generator**: the build writes each platform's sources into that platform's
own package — `@dazzlabs/dazzui-react` today, `packages/dart/dazzui` and the others as
they land — so a platform package builds and ships without the design system
installed beside it.

## Building

From this directory:

```bash
pnpm build
```

Or from the workspace root:

```bash
pnpm tokens
```

## Output

`dist/` is staging: the plugins write there, and `distribute()` in
`scripts/build.mjs` copies each platform's files into its package, where they
are committed.

| File             | What it is                                                     | Goes to                            |
| ---------------- | -------------------------------------------------------------- | ---------------------------------- |
| `style.css`      | Every token as a CSS custom property. The contract for the web. | `packages/js/dazzui-react/src/generated/`          |
| `control.css`    | The ramp bindings and the resolved interactive colour recipes.  | `packages/js/dazzui-react/src/generated/`          |
| `flutter/*.dart` | Dart sources for the Flutter package.                           | nowhere yet — awaiting `packages/dart/dazzui` |

Adding a platform means adding an entry to `TARGETS` in `scripts/build.mjs`.

`control.css` exists because CSS cannot index a colour ramp by a variable.
`plugins/control.mjs` resolves the `control.color.*` recipes at build time so
no stylesheet has to write a shade number down. See [`specs/tokens.md`](../specs/tokens.md) for
the rules that come with it.

## Layers

- **Base primitives** (`base.*`) — raw Tailwind-derived values.
  `tokens/global/_base.json` is generated by `pnpm sync`; never hand-edit it.
- **Semantic globals** — `color`, `radius`, `spacing`, `typography`, `effect`,
  `focus`.
- **Component tokens** (`tokens/component/*.json`) — one file per component.

A new token file is only built once it is listed in `terrazzo.config.mjs`.
